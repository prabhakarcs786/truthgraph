0:00 — Which answer applies?
Meet TruthGraph. It's built with Sanity Context to answer a simple question: which rule actually applies? Because when rules change, finding a relevant document is only the first step.

Let's open the guided tour. You can try these examples without an access code.

0:17 — 01 / A rule changes
Say a goalkeeper holds the ball for too long. What happens next? Today, more than eight seconds means a corner kick. TruthGraph cites the rule behind that answer and keeps the older version available for comparison.

0:30 — 02 / The date changes the answer
Now, let's ask the same question for a match on March first, twenty twenty-five. This time, it's six seconds and an indirect free kick. The keyword result finds the newer rule, but TruthGraph explains why that rule didn't apply yet.

0:44 — 03 / Missing context stays visible
What about substitutes? How many can a team use? That depends on the match. So TruthGraph asks for the missing context before giving a number. Club friendlies, international friendlies, and competition matches have different conditions.
